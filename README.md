# PersonalWebsite

PersonalWebsite for my portfolio and stuff

## Getting Started

1. Go to the `backend` directory.
2. Create a virtual environment:
   ```bash
   python -m venv venv
   ```
3. Pull (download) the `requirements.txt` file if you don't have it.
4. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the backend:
   ```bash
   python backend.py
   ```
